
# 🐉 DragonCLI - Terminal Dragon Engine

A fantasy terminal animation project built using Bash scripting and ANSI-style rendering.

Inspired by traditional Naga dragon designs with green, gold and teal aesthetics.

## Features

- Real-time ASCII dragon animation
- Frame-based rendering
- Lightweight shell implementation
- Zero external dependencies
- Linux/macOS terminal compatible

## Run

```bash
chmod +x dragon.sh
./dragon.sh
```
